How it behaves

  • Idle motion is CSS only: breathing, a blink every 6 s, a slow wave, Zs while resting. JS runs only while progress moves, then stops.
  • In Anki the board sits on the Decks screen, so progress made while reviewing plays back when you return: the character catches up to the new count.
  • A missed day is a low, flat day before today (the logo's day off), and the end moves a day later. Nothing turns warm or red.
  • Reduced motion (the system setting, or the switch above) shows one still frame per state that still tells the story.
  • Port: comeback.js and comeback.css. Comeback.mount(el, model) returns set, review(n) and cheer(who); draw(model) and words(model) are pure.
